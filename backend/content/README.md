# backend/content/

This folder just holds **text and data** — there's no real logic here, just information the app displays.

## What's in this folder

| File | What it does |
|---|---|
| `learn_content.py` | Holds everything shown on the "Learn SQL" page: short lessons (like what `SELECT` or `JOIN` do, with an example query) and a list of frequently asked questions. |

If you want to add a new lesson to the "Learn SQL" page, or change one of the FAQ answers, this is the only file you need to edit — no other code needs to change.
